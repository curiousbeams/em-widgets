em-widgets harness

Serve this directory over HTTP (npm run serve, then open /test/) — file:// will not work, because the widget fetches the notebook and imports ES modules. The widget is mounted in a real open shadow root, exactly as MyST's theme mounts it, so styling behaves the same here as on the site. On localhost the published kit URL is rewritten to this checkout, so edits to kit/ take effect on reload.
